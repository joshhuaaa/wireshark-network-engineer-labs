# Wireshark Traffic Analysis

## 01 — DNS Analysis

### Objective

Investigate DNS traffic generated by the Linux virtual machine when accessing a website.

### Findings

The capture showed the VM sending a DNS query to the configured DNS server.

I was able to identify:

* Source IP address
* DNS server IP address
* Requested domain
* DNS response
* Resolved IP address

## 03 — Web Traffic Analysis

### Objective

Analyse traffic generated by the Linux VM while accessing a website.

### Findings

The capture contained:

* DNS resolution
* TCP connections
* Source and destination IP addresses
* Source and destination ports
* Web traffic

I also observed the difference between HTTP and HTTPS traffic and how encryption affects the information visible during packet analysis.

### Security Relevance

Network analysts can use packet captures to investigate communication between hosts and identify potentially unusual activity.

## Key Takeaways

This investigation helped me develop practical experience with:

* Wireshark
* Packet capture
* DNS
* TCP
* HTTP/HTTPS
* IP addresses
* Network traffic analysis

The main lesson was that understanding **normal network behaviour** is important when trying to identify abnormal or suspicious activity.
